
# Project Overview

## Vision

To explore how computational methods can expand the possibilities of landscape architecture by making spatial design processes more dynamic, parametric and iterative.

## Problem

Early-stage landscape design often involves manually exploring spatial arrangements, functional requirements, circulation patterns and geometric relationships.

When design requirements change, multiple parts of a layout may need to be adjusted manually.

## Proposed Approach

The project explores a computational design environment where spatial requirements and design parameters can be translated into alternative landscape layouts.

The system will focus on relationships between:

- Site geometry
- Functional spatial allocation
- Circulation networks
- Parametric geometry
- Design constraints
- Alternative design scenarios

## Initial Application

The first application will focus on conceptual park and public-space design.

Users should be able to define a site, specify spatial requirements and explore multiple generated design alternatives.

## Design Philosophy

The system is intended to support the creative process of landscape architects, not replace professional design judgement.

Generated alternatives should be editable, interpretable and useful as starting points for further design development.

## Research and Development Focus

The project will investigate computational geometry, parametric modelling, algorithmic design generation, optimization and interactive visualization.
